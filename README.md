## 1. The input format
The input graph is asked to be in DIMACS ascii format for undirected graphs.

## 2. Usage

The command to run InfVC is:
```
./InfVC <instance name> <seed> <cut-off time>
```
InfVC terminates when reaching the cutoff time.

Note that the InfVC needs cplex solver

## 3. Output
<instance name> <seed> <result>
